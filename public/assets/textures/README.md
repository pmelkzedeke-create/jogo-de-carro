# Texturas de pista e cenário

As texturas atuais (asfalto, zebras, grama, terreno, concreto, metal corrugado, público, faixas) são geradas
proceduralmente em `src/rendering/ProceduralTextures.ts` no carregamento. Esta pasta é destinada a texturas
fotográficas/PBR licenciadas que venham a substituí-las.
